# Garbage Collection Privacy Policy

## 1. Information Stored

If you link your TETR.IO account, Garbage Collector stores your Discord user ID and a text string identifying your TETR.IO account. The bot uses this link to look up your account without requiring you to enter it each time.

## 2. TETR.IO API

Garbage Collector retrieves information from the TETRA CHANNEL API to respond to commands.

## 3. Storage

Account links are stored on a server operated by the bot’s creator.

## 4. Retention and Deletion

Your account link is kept for as long as your account remains linked. You can delete it at any time using the unlink command.

Garbage Collector does not store other user data.
